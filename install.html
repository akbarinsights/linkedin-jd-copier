Copy the JD

One selected LinkedIn job. Clean text, paragraphs and bullets. Nothing uploaded.

Recommended: persistent button

  1. Install Tampermonkey from your browser's official extension store (Chrome, Edge or Firefox).
  2. Open its dashboard and choose Create a new script.
  3. Replace the template with all of linkedin-copy-jd.user.js, then save.
  4. Allow the manager to run on LinkedIn. If Chrome/Edge asks for Allow User Scripts, enable it for the manager. Older versions may require Developer mode.
  5. Reload LinkedIn. Open a job and click Copy the JD at bottom-right.

Matching LinkedIn pages includes the feed so navigating from the feed into Jobs works without a reload. The button is shown only on Jobs pages.

No extension: bookmarklet

Show the bookmarks bar, then drag this link onto it:

Copy the JD

Open a LinkedIn job, then click the bookmark. It copies the selected job immediately. If clipboard access is blocked, a text box opens for Ctrl+C (Mac: Command+C).

Can't drag? Create a bookmark, name it Copy the JD, and paste the complete one-line code below into its URL/Location field.

Paste into a bookmark's URL field, not the address bar. The code is self-contained and makes no network requests. Browser policy or site security can block bookmarklets.

Unknown layout or loading job? The tool reports an error rather than copying the entire page. English heading fallback; other UI languages rely on recognised structural selectors.
